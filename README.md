# 📊 Sales Analysis SQL Project

## 📌 Overview
This project is a complete SQL-based Sales Analysis using a structured dataset. It demonstrates how to analyze customer behavior, revenue trends, and product performance using SQL queries.

The database consists of two tables:
- Customers
- Sales

---

## 🗂️ Database Structure

### 1. Customers Table
Contains customer details:
- customer_id (Primary Key)
- customer_name
- city

### 2. Sales Table
Contains transaction details:
- sale_id (Primary Key)
- customer_id (Foreign Key)
- product_name
- category
- quantity
- price
- sale_date

---

## 📈 Key Analysis Performed

### 🔹 Customer Insights
- Total spending per customer
- Top 5 highest spending customers
- Customers who purchased in both January and February
- Customers who never bought Electronics

### 🔹 Sales & Revenue Analysis
- Total revenue by category
- Monthly sales revenue
- Running total of sales
- Category-wise revenue contribution (%)

### 🔹 Product Analysis
- Most sold product (by quantity)
- Product with highest revenue
- Highest sale in each category
- Second highest sale price

### 🔹 Advanced SQL Concepts Used
- JOINs
- GROUP BY & HAVING
- Aggregate Functions (SUM, AVG, MAX)
- Window Functions (RANK, DENSE_RANK, RUNNING TOTAL)
- Subqueries
- CASE Statements
